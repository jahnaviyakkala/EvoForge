# Software Requirements Specification (SRS)
## Overview
- [NEW] The system shall implement a Calculator component in C++.
## Functional Requirements
- [NEW] The system shall provide primary operations for Calculator.
- [NEW] The system shall support inspection and status queries for Calculator.
- [NEW] The system shall safely handle invalid operations, boundary conditions, and memory allocation.
- [NEW] The system shall compile using a generated Makefile and run automated unit tests.
## Non-Functional Requirements
- [NEW] The implementation shall use idiomatic, standards-compliant C++.
- [NEW] The code shall be organized into header/source files and a test runner.
- [NEW] The system shall include documentation describing build and usage instructions.
