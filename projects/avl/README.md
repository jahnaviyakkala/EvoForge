# AVL Tree Project

An educational implementation of an **AVL (Adelson‑Velsky & Landis) self‑balancing binary search tree** written in Python 3.  
The project demonstrates key operations such as insertion, deletion, searching, and traversal while maintaining the AVL balance property.

> **TL;DR** – Run `python main.py` to launch an interactive CLI that lets you manipulate a tree and see its structure in real time.

## Features

| Feature | Description |
|---------|-------------|
| **Insertion** | Add a key while keeping the tree balanced. |
| **Deletion** | Remove a key and rebalance automatically. |
| **Search** | Find whether a key exists in O(log n). |
| **Traversals** | In‑order, pre‑order, post‑order listings. |
| **Height & Balance Factor** | Query the height of any node or its balance factor (left‑height – right‑height). |
| **ASCII Tree Visualization** | Print a human‑readable representation of the current tree structure. |
| **CLI Menu** | Simple text menu for interactive use. |
| **Unit Tests** | Comprehensive test suite covering all public APIs. |
