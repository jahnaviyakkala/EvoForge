# AVL Tree User Manual

## Step-by-Step CLI Usage

1. **Start the Application**
   - Open your terminal.
   - Navigate to the project directory:
     ```bash
     cd /home/pss/project/projects/avl
     ```
   - Run the application:
     ```bash
     python main.py
     # or if there's a compiled executable
     ./executable
     ```

2. **Available Menu Options**
   - **Insert**: Insert a new element into the AVL Tree.
   - **Delete**: Delete an existing element from the AVL Tree.
   - **Search**: Search for an element in the AVL Tree.
   - **Display**: Display the current state of the AVL Tree.
   - **Exit**: Exit the application.

3. **Example Inputs**
   - To insert a new element:
     ```
     Insert 10
     ```
   - To delete an existing element:
     ```
     Delete 5
     ```
   - To search for an element:
     ```
     Search 7
     ```

4. **Expected Outputs**
   - After inserting an element: Confirmation message and updated tree structure.
   - After deleting an element: Confirmation message and updated tree structure.
   - After searching for an element: Result indicating whether the element was found or not.

5. **Exit Procedures**
   - Type `Exit` in the command line interface to terminate the application.
   - Alternatively, you can press `Ctrl+C` to force exit.
