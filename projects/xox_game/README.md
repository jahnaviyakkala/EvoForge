# XOX Game Project

## Installation Guide

To install the XOX game, follow these steps:

1. **Clone the Repository:**
   ```bash
   git clone https://github.com/your-repo/xox_game.git
   cd xox_game
   ```

2. **Install Dependencies:**
   Ensure you have Python 3.x installed. You can install the required dependencies using pip:
   ```bash
   pip install -r requirements.txt
   ```

## System Prerequisites

- **Operating System:** Linux, macOS, Windows (with WSL)
- **Python Version:** 3.6 or higher
- **Build Tools:** `make` (for building the project)

## Feature List

- Single-player mode against AI.
- Multiplayer mode for two players.
- Game board visualization in the terminal.
- Score tracking and game history.
