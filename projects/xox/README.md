# XOX – Command Line Tic‑Tac‑Toe

XOX is a lightweight, fully‑featured command line implementation of the classic Tic‑Tac‑Toe game.  
It supports:

* Two‑player mode (human vs human)
* Human vs AI with three difficulty levels (Easy, Medium, Hard)
* Save / Load games in JSON format
* Custom board size (3×3 by default, but any odd square ≥ 3 is supported)
* Simple, text‑based UI that works on Windows, macOS and Linux

The project is written in **Python 3.10+** and uses a small set of pure‑Python modules – no external binaries are required.

---

## System Prerequisites

| Component | Minimum Version |
|-----------|-----------------|
| Python    | 3.10            |
| pip       | 20.0+           |

The project has no native extensions, so the standard `make` tool is only used for convenience (running tests, linting, etc.).
