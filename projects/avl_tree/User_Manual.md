# AVL Tree User Manual

## Introduction
This user manual provides step-by-step instructions on how to interact with the AVL Tree project. The AVL Tree is a self-balancing binary search tree, and this application allows you to perform basic operations such as insert, delete, and search.

## CLI Usage
1. **Start the Application**
   - Open your terminal.
   - Navigate to the project directory `/home/pss/project/projects/avl_tree`.
   - Run the main program using one of the following commands:
     ```bash
     python main.py
     # or
     ./executable
     ```

2. **Available Menu Options**
   - Once the application is running, you will see a menu with the following options:
     1. Insert a new node.
     2. Delete an existing node.
     3. Search for a node.
     4. Display the tree structure.
     5. Exit the application.

3. **Example Inputs**
   - To insert a new node, enter `1` and then input the value of the node you want to add.
   - To delete an existing node, enter `2` and then input the value of the node you want to remove.
   - To search for a node, enter `3` and then input the value of the node you are looking for.

4. **Expected Outputs**
   - After performing any operation, the application will display the result of the operation.
   - For example, if you insert a new node, it might display "Node inserted successfully."
   - If you search for a node, it might display either "Node found" or "Node not found."

5. **Exit Procedures**
   - To exit the application, enter `5` when prompted by the menu.
   - Alternatively, you can press `Ctrl+C` in your terminal to terminate the program.

## Conclusion
This user manual should help you effectively use the AVL Tree project for performing basic operations on an AVL tree. If you encounter any issues or have further questions, please refer to the documentation or contact the support team.
